# 71Bite

Developed a restaurant web application using Laravel, PHP, MySQL, Blade, and Vite, focused on online food ordering and customer engagement.

- Built core customer flows for browsing menu categories, adding items to a cart, updating quantities, and placing orders.
- Implemented table reservations, customer feedback submission, and authentication-protected user actions.
- Created an admin area to manage orders, reservations, feedback, and user accounts.
- Used Laravel MVC structure with routing, controllers, models, middleware, and database migrations.
