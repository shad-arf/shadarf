# Pertwk

Developed a multi-tenant bookstore platform using Laravel 10, Nuxt 4, and Vue 3. Built and integrated the REST API backend, SSR customer storefront, and admin dashboard, with features for catalog and inventory management, order workflows, authentication, role-based access control, and tenant-aware store isolation.

**Tech Stack:** Laravel, PHP, Nuxt 4, Vue 3, Pinia, Tailwind CSS, MySQL, REST API
